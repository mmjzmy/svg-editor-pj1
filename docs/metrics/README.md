# Phase 2 metrics

Generated by `git diff --stat final..p2` and `git diff --numstat final..p2`; dependency directories and build output are excluded. CLI changes are grouped into kernel (`src/domain`, `src/commands`, `src/application`, `src/presentation`), assembly (`src/main.ts`, `src/cli`, `src/plugin`) and plugins (`plugins`). The VSCode extension is measured separately under `extension`. Final values are recorded after the `p2` tag is created.
